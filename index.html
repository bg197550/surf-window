Marine model: Open-Meteo / DWD. Weather: Open-Meteo. Tides: NOAA CO-OPS predictions from the nearest reference station. Surf windows and beach surf heights are automated estimates: offshore model waves are converted to approximate breaking height using swell period and the angle of approach to each beach. Offshore model wave height is not breaking wave height at the beach. Wind exposure is an estimate based on the beach’s general orientation; local conditions can vary. Cam feeds belong to their publishers; availability and embedding depend on each provider. Forecasts and conditions can differ across sources.
